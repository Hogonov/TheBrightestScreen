# TheBrightestScreen

Бесплатное локальное приложение для повышения яркости Apple XDR на macOS 13+. Сборка для Apple Silicon, без зависимостей, подписки и сети.

## Запуск

Откройте `build/Brighter.app`. В строке меню появится солнце. Нажмите **Максимальная яркость**: Brighter выставит системную яркость на 100% и включит XDR. При обычном запуске усиление выключено. При желании скопируйте приложение в «Программы».

- **Включить XDR** повышает диапазон яркости, сохраняя текущую системную настройку.
- **Усиление XDR** регулирует дополнительное усиление от 0 до 100% (это не измерение яркости в нитах).
- **Выключить XDR** возвращает исходную гамму и системную яркость, если она всё ещё на выставленном приложением максимуме. Изменения клавишами яркости сохраняются.
- **Выключить и выйти** восстанавливает настройки и закрывает приложение.
- Сначала закройте BrightXDR, Vivid или BrightIntosh, если они запущены.

## Сборка и проверка

Нужны Xcode Command Line Tools и macOS:

```sh
bash scripts/build.sh
bash scripts/test.sh
build/Brighter.app/Contents/MacOS/Brighter --diagnose
build/Brighter.app/Contents/MacOS/Brighter --smoke-test
```

`--diagnose` только читает состояние. `--smoke-test` на 9 секунд включает максимум, проверяет реальное применение гаммы, ограниченный размер окон и восстановление, затем завершает процесс. Перед этим закройте уже запущенный Brighter. Этот тест вызывает обработчик смены Spaces, но сам рабочие столы не переключает.

Для проверки конкретной системы включите максимум, несколько раз переключите Spaces и полноэкранное приложение, откройте/закройте Mission Control, затем выключите XDR. Физическую яркость и отсутствие кратких вспышек следует оценивать на самом дисплее: скриншот не измеряет ниты.

Опция `--enable` запускает сразу с максимальной яркостью. Автозапуск не включается автоматически. `SIGTERM`, `SIGINT`, `SIGHUP` обрабатываются с восстановлением состояния; после принудительного `SIGKILL` восстановление системного ползунка не гарантируется.

Сборка подписана локальной ad-hoc подписью, без Apple notarization. Исходный код и лицензия приложены. Основано на подходе [BrightIntosh](https://github.com/niklasr22/BrightIntosh); см. `THIRD_PARTY_NOTICES.md` и `LICENSE`.
